# 04 Claude Code Start Here

## Copy this prompt into Claude Code
Read the three documents 01_Product_Requirements.docx, 02_Technical_Architecture.docx, and 03_Implementation_Plan.docx (or the matching Markdown files included in this folder). Implement ONLY the Tonight demo milestone. Use Next.js App Router, TypeScript and Tailwind. Build a polished responsive mobile-first School Hub demo with fictional information for two children at separate schools. Include Home, Inbox, Calendar and Share navigation, child filtering, task completion, source labels and clear DEMO labeling. Do not add authentication, databases, external APIs, secrets, or real student information. The Share page should honestly state that extraction is not yet connected. Run lint/type/build checks, fix failures, give local launch instructions, and summarize changes. Ask before expanding scope or adding major dependencies.

## Quick start
1. Unzip the starter pack into a new project folder. 2. Open that folder in Claude Code. 3. Paste the prompt above. 4. Run the app locally. 5. Show Morgan on an iPhone-sized screen and capture feedback. 6. Commit to your GitHub repository.

## Important
Never paste school credentials, private student records, or real children’s school communications into a public demo or unsecured coding session.
